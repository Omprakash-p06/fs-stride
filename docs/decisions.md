# Canonical Design Decisions (`fs-stride`)

**Canonical hierarchy:** `AGENTS.md` > `RESEARCH_PLAN.md` > `Spec v2.0.md` > `README.md` for design decisions; `Spec v2.0.md` > `RESEARCH_PLAN.md` > `AGENTS.md` > `README.md` for interface contracts (FRs, NFRs, test IDs, schemas, CLI flags). Conflicts are resolved in this file.

| # | Decision | Chosen Canonical Value | Rationale | Authoritative Source |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **C file layout** | **5 files:** `src/main.c`, `src/topo.c`, `src/alloc.c`, `src/kernel.c`, `src/fs_stride.h` | Matches `AGENTS.md` §0.3/§4.2 and enables isolated disassembly (`UT-04`) and allocator/layout unit tests (`UT-02`, `UT-03`) under `<= 400` C LOC. | `AGENTS.md` §4.2, `Spec v2.0.md` §9–10 |
| 2 | **Kernel mode names** | **`atomic`, `coupled-pair`, `volatile`, `rw-asymmetric`** | `coupled-pair` documents the Regime B ping-pong pair mechanism; `rw-asymmetric` captures reader/writer non-atomic contention. | `RESEARCH_PLAN.md` Defects 1–2, `AGENTS.md` §4.5 |
| 3 | **Placement names** | **`cores`, `smt-sibling`, `spread`** (`smt-sibling` exploratory-only; `spread` allowed on `cores`-equivalent primaries) | Distinguishes intra-socket physical cores (`cores`), SMT siblings sharing L1D (`smt-sibling`), and cross-socket/package spread (`spread`). | `RESEARCH_PLAN.md` Defect 4, `C-B01`/`C-B05` |
| 4 | **Memory allocator** | **`posix_memalign(&ptr, 4096, round_up_4096(raw_size))`** followed by `memset` (and `atomic_init` for `_Atomic` counters) | `aligned_alloc(4096, raw_size)` violates strict C11 when `raw_size` is not a multiple of 4096 and aborts under LLVM Scudo. | `Spec v2.0.md` FR-03, `RESEARCH_PLAN.md` Defect 3 |
| 5 | **Chunk size & loop structure** | **`K = 65,536` ops**; `barrier -> t_start -> K ops -> barrier -> check elapsed >= target -> repeat`; **`UT-14` widened to `50–100 ms`** (`warning only` when `last_chunk_duration / cell_duration > 0.25`) | `1,024`-op chunks incur excessive barrier/timer overhead under 22x contention; `65,536` executes >330k contended ops per 50 ms cell without a separate stop-flag poll. | `RESEARCH_PLAN.md` Calc 3, `AGENTS.md` §4.6, `C-B03` |
| 6 | **`raw.csv` schema** | **14 columns:** `run_id,host,mode,stride,threads,placement,block,order,role,total_ops,elapsed_s,ns_per_op,cpus,loadavg1` | Retains `run_id` for multi-run aggregation, `role` (`ref`/`test`/`sentinel`), `cpus` (`sched_getcpu()` verification), and `loadavg1` noise context. | `Spec v2.0.md` §7 |
| 7 | **`ns_per_op` formula** | **`elapsed_s * 1e9 * threads / total_ops`**, where `total_ops` is the **sum across all threads** | Unambiguous mean per-thread operation latency; eliminates factor-of-`threads` confusion. | `Spec v2.0.md` FR-07, `AGENTS.md` §4.6 |
| 8 | **Primary family (`m`) & reference** | **`m = 5`** (`8, 16, 32, 64, 128` B vs `256` B reference; **`512` B is exploratory**); **`cores` / `spread` only** (`smt-sibling` and `volatile` and `t < max` are exploratory) | Matches FR-11 fixed primary family and excludes shared-L1D `smt-sibling` from cross-core confirmatory inference. Exploratory configs still receive descriptive `class`/`knee_bytes` in the exploratory table. | `Spec v2.0.md` FR-11, `C-B04`/`C-B05` |
| 9 | **Effect floor & `MDE90` gate** | **1% practical floor** (`exp(mean_log_ratio) - 1 > 0.01`); **`mde90` stored internally as fraction**, gate **`mde90 > 0.10`** (`--strict-h1` sets `0.05` for H1 tests); outputs emit **`mde90_pct = 100 * mde90`** | 1% floor preserves sensitivity to 2–3% H1 prefetcher effects; internal fraction avoids `* 100` gate confusion while `_pct` fields keep outputs human-readable. | `RESEARCH_PLAN.md` Decision Rule, `C-B04` |
| 10 | **Simultaneous 99% CIs** | **Bonferroni-adjusted `scipy.stats.t.ppf(1 - 0.01 / (2 * m), B - 1)`** (`m = 5`) | Aligns 99% simultaneous confidence intervals with family-wise `alpha = 0.01` Holm inference. | `C-M04`, `RESEARCH_PLAN.md` |
| 11 | **Knee & `512 < 256` (`irregular`)** | **`knee = s*`**: smallest stride `s*` such that **`s*` is uncontended AND every stride `s > s*` is uncontended** (no `s >= s*` contended). Significant `512 < 256` speedup -> **`irregular`**, `knee_bytes = None`, `log.warning("faster-wider detected at stride %d; not a knee", s)` | Ensures `64` contended + `128` uncontended returns `knee = 128 B` (`pair128`) and prevents mislabeling `512 < 256` speedups as `flat`. | `Spec v2.0.md` §7, `RESEARCH_PLAN.md`, `C-B04` |
| 12 | **Block count & ST validation** | **`B = 30`** (`31` blocks with block `0` warm-up discarded); **`ST-01`: 2,000 sweeps**; **`ST-02`: 1,000 sweeps** with 5% slowdown injected at **stride 64 only** (checking per-stride Holm detection power `>= 90%`) | `B = 30` yields `t_{29}` critical values matching the audit power table; `ST-01`/`ST-02` counts match the audit validation tables. | `Spec v2.0.md` FR-08, `RESEARCH_PLAN.md`, `C-M03` |
| 13 | **Phasing (MVP vs Phase 2)** | **Phase 1 MVP:** `T00–T13` + `make smoke` + `make test-sim` + local pilot + `ci.yml` (`measure.yml` weekly-only). **Phase 2 (post-Gate G1):** `T14–T20` (`c2c_check.sh`, `msr_ablate.sh`, `release.yml`, Zenodo/DOI, `validate-data.yml`, `atlas.md` + `knee_by_machine.png`, `resolve_pins.sh`, `license_check.sh`, Compile Farm multi-ISA) | Validates hypotheses and noise floor on pilot hardware before building release, community PR bot, and multi-ISA infrastructure. | `C-M01`, `Spec v2.0.md` §14–15 |
| 14 | **CI `cloc` gate & `cli.py` exit codes** | **`cloc` (`<= 400` C / `<= 600` Python) is a hard CI fail** in `ci.yml`; **`cli.py` exit codes: `0` (ok), `1` (missing `raw.csv` / required JSON), `2` (bad CLI arg), `3` (affinity failure)** (exit code `4` removed) | Enforces codebase auditability across PRs and eliminates orphaned exit code `4`. | `Spec v2.0.md` NFR-06, `C-M06`/`C-M07` |
| 15 | **MSR ablation & CPython citations** | **`msr_ablate.sh` (Phase 2):** `--intel` (`0x1A4` bit 1) + `--amd` (`0xC0000108`, Zen 4/5 only; exit `0` + message on Zen 2/unsupported), dry-run default, `--confirm`, restore-on-exit, root, never on default path. **Citations:** cite **both** `gh-144438` (Feb 2026) and `#159860` (Oct 2026) in `docs/related-work.md` | Covers Intel and modern AMD causal ablation safely while distinguishing the two distinct CPython false-sharing bugs. | `RESEARCH_PLAN.md`, `Spec v2.0.md` §2/§17, `C-M07` |
